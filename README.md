## What It Does

Apex Sensitivity Lab is a single-page browser application that works offline and helps Apex Legends players examine and improve their mouse sensitivity. Five Canvas-based aim exercises use Pointer Lock input to assess different aiming dimensions and produce a useful personalized sensitivity baseline.

Alongside the testing workflow, the tool includes sensitivity conversion across FPS games, a collection of pro player configurations, and utilities for examining Apex settings. Everything runs on the local device in the browser, and saved information stays in local browser storage instead of being sent to a remote service.

- Assess sensitivity through five separate aiming dimensions

## Frequently Asked Questions

### How can I open the utility?

Load the [latest build](https://seanwardzoi9315.github.io/apex-sensitivity-aim-lab/) in a web browser. From there, you can start an aim exercise or choose one of the other available tools.

### What is the purpose of Pointer Lock?

The Canvas exercises use Pointer Lock to receive continuous mouse movement while you aim. Accept the browser permission request to enable this behavior.

### Will it work offline?

Yes. Once the application is available on the device, it is intended to operate locally in the browser. Its active data is stored locally as well.

### What determines the sensitivity recommendation?

The recommendation is calculated from the outcomes of the utility's five-dimensional aiming exercises and is provided as a personalized reference.

### Is sensitivity conversion for other FPS games supported?

Yes. The included cross-FPS converter helps compare and translate sensitivity values between supported FPS configurations.

### Can the generated setup be adjusted?

Yes. Test results, conversion options, and the Apex settings optimization tools can all be used while shaping a configuration for your preferred setup.

### Where does the application save information?

Saved data is stored in the browser's local storage on the device being used. Removing browser storage can also remove the saved information.

### What should I check if an aim exercise does not react?

Confirm that Pointer Lock is permitted, click within the exercise area, and ensure the page is running in a browser that supports both Canvas and Pointer Lock.
